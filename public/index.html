OAuth 2.0 Authorization Code Flow Demo

1

Initiate OAuth Flow

In the OAuth flow, the first step is to redirect to the authorization endpoint:

GET /login
Redirects to Auth0's authorization endpoint
https://${AUTH0_DOMAIN}/authorize? response_type=code& client_id=${CLIENT_ID}& redirect_uri=${CALLBACK_URL}& scope=openid+profile+email& state=${RANDOM_STATE}& code_challenge=${S256_CHALLENGE}& code_challenge_method=S256

state protects against CSRF. code_challenge is PKCE: it binds the authorization code to this client, so a stolen code cannot be redeemed by anyone else.

2

User Authentication

At Auth0's login page:

1. User enters credentials
Auth0 validates credentials
2. User consents to requested permissions
3

Authorization Code Grant

After successful authentication:

Auth0 redirects back to your application
With authorization code
${CALLBACK_URL}?code=AUTHORIZATION_CODE&state=${RANDOM_STATE}
4

Token Exchange

Your server exchanges the authorization code for tokens:

POST to Auth0's token endpoint
POST https://${AUTH0_DOMAIN}/oauth/token { "grant_type": "authorization_code", "code": "AUTHORIZATION_CODE", "client_id": "${CLIENT_ID}", "client_secret": "${CLIENT_SECRET}", "code_verifier": "${PKCE_VERIFIER}", "redirect_uri": "${CALLBACK_URL}" }
Returns access & ID tokens

This request happens server to server. The client secret never reaches the browser.

5

Success!

Authentication complete:

✓ User is authenticated
✓ Session cookie issued (HttpOnly)
✓ User profile information available
